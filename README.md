# Ma Collection

Application d'inventaire de collection (jeux vidéo, jouets, maillots, consoles, ballons, accessoires…).

- Site statique (HTML, CSS, JavaScript), hébergé sur GitHub Pages.
- Données, comptes et photos : Supabase (`supabase/schema.sql` crée les tables, les règles de sécurité et le stockage des photos).
- Les photos sont réduites dans le navigateur avant l'envoi (640 px, WebP, 50 Ko maximum).
- Fonds d'écran rétro au choix, cartes en formes spéciales, logo personnalisable (fichier JPEG/PNG/SVG ou lien).
